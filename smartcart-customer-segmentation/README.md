# 🛒 SmartCart – Customer Segmentation Using Clustering

## 📌 Project Overview
SmartCart is a customer segmentation project focused on exploring customer data and identifying meaningful customer groups using unsupervised machine learning.

The project aims to discover patterns in customer behaviour and understand how clustering can help businesses make better data-driven decisions.

## 🎯 Objectives
- Explore and analyse customer data.
- Perform data preprocessing and exploratory data analysis.
- Apply clustering techniques to segment customers.
- Understand the characteristics of different customer groups.
- Identify potential business insights from customer segments.

## 🔍 Project Workflow
- Data Loading
- Data Exploration
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Preparation
- Clustering
- Cluster Analysis & Interpretation
- Business Insights

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📊 Business Applications
Customer segmentation can help businesses:
- Understand different customer groups.
- Develop targeted marketing strategies.
- Improve customer engagement.
- Identify purchasing behaviour patterns.
- Support data-driven business decisions.
